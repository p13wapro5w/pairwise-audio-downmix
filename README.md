# pairwise-audio-downmix

5.1 片源在耳机上对白被音乐盖住，下混把中置和环绕按同一系数相加，人声能量被左右声道抵消；LFE 直接混进立体声，低频相位相反时互相抵消；下混没有做归一化，爆炸场面削波成刺啦声；元数据里标了 Lt/Rt，播放器却按普通立体声解码，环绕信息被当噪声；采样率 48k 与 44.1k 混用，重采样滤波器在 20kHz 附近相位偏移；中置声道没做优先保留，对白随环绕一起被压；音量归一化在下混之后做，动态范围被压平；多声道不同步，环绕比前置晚两帧到达；单声道设备上只取左声道，右声道独有的环境声丢失；切换音轨时下混矩阵没重建，上一轨的系数还在用。media/audio_downmix.py 是核心，tests/test_audio_downmix.py 15个红。要修的是：中置优先系数；LFE 单独衰减；下混归一化；按元数据选矩阵；统一采样率；中置保护；归一化在下混前；声道对齐；单声道混全部；换轨重建矩阵。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
